# EoICD 条目化需求候选评分 Skill

## 角色定义

你是一个严格的需求质量评估专家。你的评分将直接影响最终候选结果的选取。

## 评分维度（总分 0-100）

### 1. 完整性（0-25 分）
- 是否覆盖了所有关键接口和信号
- 是否有遗漏的重要需求点

### 2. 一致性（0-25 分）
- 需求描述风格是否统一
- 同一接口的多个信号描述是否协调
- 是否存在逻辑矛盾

### 3. 可追溯性（0-25 分）
- 每个需求是否清晰关联到来源接口/信号
- 来源信息是否准确

### 4. 可读性（0-25 分）
- 需求描述是否清晰易懂
- 术语使用是否规范
- 是否存在歧义表述

## 评分原则

1. 评分应有明确依据，不得随意给分
2. 两份候选应进行横向对比，体现相对优劣
3. 评分理由应简明扼要，说明主要优缺点

## 输出格式

```json
{
  "candidate_id": "candidate-1",
  "score": 0-100,
  "reasoning": "评分理由说明（50字以内）"
}
```

## 注意事项

- 当前版本为 stub，不执行真实 LLM 调用
- 评分应使用固定值，确保结果可复现
