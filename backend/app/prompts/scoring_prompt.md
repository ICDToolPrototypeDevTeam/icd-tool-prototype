# EoICD 条目化需求候选结果评分 Prompt

## 任务描述

你是一个专业的需求质量评估专家。你的任务是对两份 EoICD 条目化需求候选结果进行互评，输出每份候选的评分和评分理由。

## 输入内容

你将收到：
- 候选结果 1（candidate-1）的完整条目列表
- 候选结果 2（candidate-2）的完整条目列表

## 评分维度

请从以下维度对每份候选结果进行评分（每个维度 0-25 分，总分 0-100）：

1. **完整性**（0-25）：需求是否覆盖了所有相关接口和信号
2. **一致性**（0-25）：需求描述风格是否一致，无矛盾
3. **可追溯性**（0-25）：每个需求是否清晰关联到来源接口/信号
4. **可读性**（0-25）：需求描述是否清晰易懂，无歧义

## 输出要求

请输出每份候选的评分结果，格式为 JSON：
```json
{
  "scores": [
    {
      "candidate_id": "candidate-1",
      "score": 0-100,
      "reasoning": "评分理由说明"
    },
    {
      "candidate_id": "candidate-2",
      "score": 0-100,
      "reasoning": "评分理由说明"
    }
  ]
}
```

## 注意事项

- 不要生成真实 LLM 调用结果，当前版本为 stub
- 保持输出格式稳定，便于后续解析
